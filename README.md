# Radar bandi

Dashboard statica dei bandi monitorati (Puglia, Italia, fondazioni): scadenze e semafori di fattibilità preliminari per soggetto.

Le valutazioni sono istruttorie preliminari automatiche, non pareri di ammissibilità: fa sempre fede il bando ufficiale.
La pagina è generata da uno script locale; non modificare `index.html` a mano.
